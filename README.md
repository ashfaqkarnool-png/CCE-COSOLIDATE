# 6 ರಿಂದ 9 ನೇ ತರಗತಿಯ ನಿರಂತರ ಮತ್ತು ವ್ಯಾಪಕ ಮೌಲ್ಯಮಾಪನ ಕ್ರೋಡೀಕೃತ ವಹಿ (CCE Consolidated Register)

Karnataka State Board Continuous and Comprehensive Evaluation (CCE) Class 6–9 Consolidated Marks, Grades, Attendance, and Co-Scholastic Register.

---

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start local development server (port 3000)
npm run dev

# 3. Build for production
npm run build
```

---

## 🐙 How to Push to GitHub

If you have downloaded the code or cloned the repository:

```bash
# Initialize git (if not already initialized)
git init

# Stage all files
git add .

# Commit
git commit -m "feat: Karnataka CCE Class 6-9 Consolidated Register"

# Rename branch to main
git branch -M main

# Add your GitHub repository remote
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# Push
git push -u origin main
```

---

## 🌐 How to Host on GitHub Pages (Free Hosting)

A ready-to-use GitHub Actions workflow has been included in `.github/workflows/deploy.yml`:

1. Push your code to GitHub on the `main` branch.
2. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment** > **Source**, choose **GitHub Actions**
3. That's it! GitHub will automatically build and publish your site at:
   `https://<your-username>.github.io/<your-repo-name>/`
